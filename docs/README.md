# 游戏优化助手 · 项目文档

> 当前版本：**v1.0.2**
> 文档更新：2026-10-20

## 这是什么

一个面向 Windows 的**游戏性能诊断工具**。它不承诺「一键提速」，而是把「显存水位 + 硬件占用 + 外设状态」摆到同一屏，并提供可回滚的游戏模式。

## 一句话现状

**v1.0.2 补齐托盘运行并修掉卸载残留误报**：

- 关窗口不再退出程序，而是收进系统托盘常驻后台；托盘图标双击 / 菜单「显示主界面」可恢复窗口，「退出」才真正结束（退出前自动还原游戏模式）
- 游戏库兜底扫描不再把「卸载后只剩云存档占位文件」的空壳目录当游戏（ChainedTogether 卸载后不再入库）

## 界面

| 页面 | 内容 |
|---|---|
| 总览 | 显存 / 内存 / GPU 3D / CPU 单核峰值四个环形仪表 + 颜色图例 + 游戏模式 + 后台白名单 + 游戏列表 |
| 外设 | 每台设备一张卡片：型号、厂商、连接方式、电量环；插拔后点「重新扫描」 |
| 设置 | 版本号、采集状态、显存预算来源 |
