# 游戏优化助手 · 项目文档

> 当前版本：**v1.0.1**
> 文档更新：2026-10-20

## 这是什么

一个面向 Windows 的**游戏性能诊断工具**。它不承诺「一键提速」，而是把「显存水位 + 硬件占用 + 外设状态」摆到同一屏，并提供可回滚的游戏模式。

## 一句话现状

**v1.0.1 是 v1.0.0 的微调版**：

- 外设页不显示笔记本自带键盘
- 删除右上角页签，页面切换只保留左侧导航
- 白名单改为「开启游戏模式」旁的设置按键，点击展开带应用图标和名称的面板
- NARAKA: BLADEPOINT 显示为「永劫无间」；游戏库扫描补齐无 manifest 的 Steam 目录
- 开启游戏模式后按钮变红色「关闭游戏模式」，关闭时自动恢复被结束的进程

## 界面

| 页面 | 内容 |
|---|---|
| 总览 | 显存 / 内存 / GPU 3D / CPU 单核峰值四个环形仪表 + 颜色图例 + 游戏模式 + 后台白名单 + 游戏列表 |
| 外设 | 每台设备一张卡片：型号、厂商、连接方式、电量环；插拔后点「重新扫描」 |
| 设置 | 版本号、采集状态、显存预算来源 |
