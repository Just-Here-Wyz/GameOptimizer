# 游戏优化助手 · 项目文档

> 当前版本：**v1.1.0**
> 文档更新：2026-10-20

## 这是什么

一个面向 Windows 的**游戏性能诊断工具**。它不承诺「一键提速」，而是把「显存水位 + 硬件占用 + 外设状态」摆到同一屏，并提供可回滚的游戏模式。

## 一句话现状

**v1.1.0 连接「逆向REA」协议成果，VXE/ATK 鼠标实时读电量**：

- 外设页的 VXE / ATK（Compx 方案）无线鼠标显示真实剩余电量（本机实测 65%），不再「未知」
- 协议来自 hub.atk.pro 驱动逆向：FF02 厂商集合 16 字节包，GetBatteryLevel=4，校验和 + 实测抓包验证
- 其余能力与 v1.0.2 相同：托盘常驻、卸载残留过滤、游戏模式自动恢复
