# 游戏优化助手 · 项目文档

> 当前版本：**v0.5.1**
> 文档更新：2026-10-19

## 这是什么

一个面向 Windows 的**游戏性能诊断工具**。它不承诺「一键提速」，而是把「显存水位 + 帧时间 + 硬件占用」放进同一条时间轴，告诉你卡顿到底来自哪里，并提供可回滚的游戏模式。

## 一句话现状

**v0.5.1 是一个「能看、能测、能改、能回滚」的可用版本**：

- 首页每款游戏按自己的显存需求判「充足 / 紧张」，本机显存容量走 DXGI 实测
- 游戏模式只结束你勾选过的后台应用，系统必要进程自动保护
- 帧时间采集仍受 Windows ETW 权限限制，需要管理员身份或加入 `Performance Log Users` 组才能拿到数据

## 待办（v1.0.0 之前）

| 项 | 说明 |
|---|---|
| 数据页曲线缺量程 | 每条曲线按自身 min/max 缩放，没有刻度，看不出绝对水平 |
| 诊断结论未展示 | `DiagnosisEngine` 的结论只在关窗口时计算，界面未绑定 |
| 帧时间依赖 ETW 权限 | 普通权限下，五条曲线里最有价值的一条没有数据 |
