# 游戏优化助手 · 项目文档

> 当前版本：**v0.5.0**
> 文档更新：2026-10-19

## 这是什么

一个面向 Windows 的**游戏性能诊断工具**。它不承诺「一键提速」，而是把「显存水位 + 帧时间 + 硬件占用」放进同一条时间轴，告诉你卡顿到底来自哪里，并提供可回滚的游戏模式。

## 一句话现状

**v0.5.0 是一个「能看、能测、能改、能回滚」的可用版本**，但帧时间采集受 Windows ETW 权限限制，需要管理员身份或加入 `Performance Log Users` 组才能拿到数据。显存、内存、GPU、CPU 的采集与判定完全可用，且不需要任何特权。
