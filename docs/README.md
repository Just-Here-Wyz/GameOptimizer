# 游戏优化助手 · 项目文档

> 当前版本：**v2.2.1**
> 文档更新：2026-10-21

## 这是什么

一个面向 Windows 的**游戏性能诊断工具**。它不承诺「一键提速」，而是把「显存 / 内存 / 逐核占用 / 系统压力」摆到同一屏，并提供**全部可回滚**的游戏模式与内存优化。

## 一句话现状

**v2.x 补齐了「优化」与「看得懂 CPU」两条主线**：

| 版本 | 内容 |
|---|---|
| v2.0.0 | 首页「优化」按钮 + `MemoryCleanAction`（释放闲置工作集，不结束进程） |
| v2.0.1 | 系统压力面板（总 CPU + 磁盘吞吐，实测筛掉三项候选指标） |
| v2.0.2 | CPU 仪表改用 **P 核峰值**，修复小核负载误报 |
| v2.1.0 | CPU 详情页：每核条形图 + 一行结论 |
| v2.1.1 | 系统压力并入详情页；修复磁盘吞吐从 v2.0.1 起静默失效 |
| v2.1.2 | 修复外设页返回总览后与 CPU 详情页叠在一起、返回按钮失灵 |
| v2.2.0 | **下载页**：多线程分片 + 断点续传 + SHA1 校验 + 限速 + 任务持久化 |

## 界面

| 页面 | 内容 |
|---|---|
| 总览 | 显存 / 内存 / GPU 3D / **CPU P 核峰值** 四个环形仪表；内存下方「优化」按钮；颜色图例；游戏模式；后台白名单；游戏列表 |
| CPU 详情 | 点 CPU 仪表进入：结论 + 四项汇总（P/E/全局/总 CPU）+ 系统压力 + 按大小核分组的每核条形图 |
| 外设 | 每台设备一张卡片：型号、厂商、连接方式、电量环；插拔后点「重新扫描」 |
| 下载 | 粘贴直链新建任务；按状态分组的任务卡片（速度 / 剩余 / 进度 / SHA1 校验结论）；底部全局统计 |
| 设置 | 版本号、采集状态、显存预算来源 |

## 已知的能力边界（先看这个）

- **温度监控不做**：ACPI 只能给出不随负载变化的环境温度，真实核心温度需内核驱动（第十三节）
- **游戏内悬浮窗不做**：与「账号安全」约束冲突，做出来也没有实际价值（第十七节）
- **帧率不做**：需 PresentMon 定向监控游戏进程，是反作弊敏感点（第十七节）
- **无线键鼠电量**：仅蓝牙与 VXE/ATK（Compx）可读，其余厂商私有协议读不到（第一节）
- **下载器只认标准 HTTP 直链**：需要服务端返回 Content-Length；不支持 Range 时退化为单线程；服务端不给校验值时如实标注「未校验」（第十八节）
