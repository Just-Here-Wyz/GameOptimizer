# 功能清单（v0.5.0）

图例：✅ 完全可用 ｜ ⚠️ 有条件可用 ｜ ❌ 未实现

## 一、首页

| 功能 | 状态 | 说明 |
|---|---|---|
| 设备实时状态 | ✅ | 显存占用、内存占用/总量、GPU 3D 利用率、最高单核占用，每秒刷新 |
| 游戏库自动扫描 | ✅ | 同时扫描 Steam 与 WeGame，启动时自动执行，可手动「重新扫描」 |
| 平台分组统计 | ✅ | 标题显示「已扫描到 N 款游戏（WeGame 2 款，Steam 1 款）」 |
| 非游戏过滤 | ✅ | Wallpaper Engine、SteamVR、各类 Redistributable 不入库 |
| 显存是否达标 | ⚠️ | **当前显示「待测」**：需要先跑一局采集才有实测结论，尚未实现按游戏独立统计 |

## 二、数据页

| 功能 | 状态 | 说明 |
|---|---|---|
| 帧时间曲线 | ⚠️ | **需要 ETW 权限**，见下文 |
| 显存占用曲线 | ✅ | 最近 120 个采样点（约 2 分钟） |
| 可用内存曲线 | ✅ | 同上 |
| GPU 3D 利用率曲线 | ✅ | 同上，已钳制到 0–100 |
| 最高单核占用曲线 | ✅ | 同上 |
| 开始/停止帧采集 | ✅ | 自动识别运行中的游戏，无需手填进程名 |
| 采集失败如实上报 | ✅ | 不会在采集失败时显示「正在采集」 |
| 暂停/恢复采样 | ✅ | 暂停后停止写入曲线，时钟同步暂停 |

## 三、游戏模式

| 功能 | 状态 | 说明 |
|---|---|---|
| 高性能电源计划 | ✅ | 切到高性能，退出时恢复原计划 |
| 显卡性能偏好 | ✅ | 写入 `HKCU\...\UserGpuPreferences` |
| 关闭后台干扰进程 | ✅ | 白名单：浏览器、下载器、录屏、远控、通讯 |
| 失败自动回滚 | ✅ | 任一动作失败，立即回滚已执行部分 |
| 回滚失败上报 | ✅ | 明确告知哪项没还原，绝不静默显示「已还原」 |

## 四、诊断归因

| 功能 | 状态 | 说明 |
|---|---|---|
| 显存/内存双指标判定 | ✅ | 预算占用率 80%/90% + 内存余量 1GB/512MB |
| 帧时间尖峰识别 | ✅ | > 100ms 计为一次卡顿尖峰 |
| 1% Low / 0.1% Low | ✅ | 比平均 FPS 更能反映卡顿体感 |
| CPU 瓶颈归因 | ✅ | 尖峰时 GPU 利用率 < 60% → GPU 在等 CPU |
| 单核打满归因 | ✅ | 尖峰时单核 > 95% → 主线程瓶颈 |
| 共享显存溢出提示 | ✅ | 针对核显场景 |
| 网络延迟归因 | ❌ | 已推迟到 v2，MVP 不含 |

## 六、帧时间采集的前置条件

这是**唯一需要用户额外操作的环节**：

```
PresentMon 启动 ETW 追踪会话
  ↓ 需要以下任一条件
  ├─ 以管理员身份运行本程序
  └─ 账号加入 Performance Log Users 组，且该会话不是低完整性进程启动的
```

**已实现**：
- 自动检测运行中的游戏（含反作弊游戏）
- 失败时给出明确原因和解决办法
- 采集中断时立即上报，不谎报成功

**未实现**：
- 自动提权（需要弹 UAC）
- 帧数据的持久化保存（当前 CSV 路径仅作说明，数据走 stdout 未落盘）
